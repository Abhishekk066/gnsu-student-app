The **GNSU Student App** is the all-in-one campus super app built for students of **Gopal Narayan Singh University (GNSU)**. It combines academic ERP access, real-time attendance tracking, an ad-free browser, media streaming with SnapTube, AI assistance, and developer tools into a unified, high-performance Android experience.

## ✨ What's New in v2.0.1

### 📱 Customizable MIUI Launcher
- **Paginated App Grid**: Smooth swipeable pages with responsive dot indicator.
- **Folder Organization**: Group apps into categorized folders with instant dissolve & reordering.
- **Custom Web Shortcuts**: Pin any web application or website to your home screen with automatic favicon extraction.
- **Personalization**: Modern solid colors, GPU-accelerated gradient wallpapers, and glassmorphic UI.

### 🎬 SnapTube Player & Media Downloader
- **Background Playback**: Listen to audio or lectures in the background with lock-screen media controls.
- **Floating Mini-Player**: Drag-to-dismiss and floating Picture-in-Picture (PiP) video player.
- **Multi-Quality Downloads**: Download videos up to 1080p MP4 or convert audio up to 320kbps MP3.

### 📊 Student ERP & Academic Portal
- **Real-Time Attendance Monitoring**: Instant view of lecture attendance percentage and alerts.
- **One-Tap University Portals**: Student ERP, UCanApply, examination forms, fee payments, and admit cards.
- **University Notices**: Live updates and push notifications for college circulars and exam schedules.

### 🌐 Ad-Free Smart Web Browser
- **Integrated Ad Blocker**: Blocks trackers, malicious popups, and intrusive ads for ultra-fast browsing.
- **Tab Switcher Grid**: Manage multiple tabs with live previews.
- **Desktop Mode & Privacy Controls**: Full desktop mode rendering, incognito mode, and cache cleaner.
- **PiP Video Support**: Seamlessly pop out web videos into system Picture-in-Picture.

### 🤖 BotHive AI & Developer Hub
- **BotHive AI Assistant**: Instant campus helper and study companion.
- **Online Code Compiler**: Compile & run C, C++, Java, and Python code directly on your phone.
- **Developer Hub Shortcuts**: Direct access to GitHub, LeetCode, GeeksforGeeks, MDN, W3Schools, and HackerRank.
- **National Digital Library**: Instant access to academic e-library and research resources.

## 📥 Download & Installation

Get the latest stable APK directly from GitHub Releases:

👉 **[Download Latest v2.0.1 APK](https://github.com/Abhishekk066/gnsu-student-app/releases/latest/download/app-release.apk)**

### Installation Steps:
1. Download the `app-release.apk` file.
2. If prompted, allow **"Install unknown apps"** in your device settings.
3. Open the APK and tap **Install**.
4. Future updates can be installed directly from **Settings > Check for updates** inside the app.

## 🔐 Security & Privacy
- **Direct & Secure Sessions**: Academic credentials connect directly to university servers without intermediate storage.
- **Silenced Production Logs**: `AppLogger` ensures zero debug logs, network payloads, or user tokens leak in production.
- **Scoped Storage & Permissions**: Granular Android permissions for camera, microphone, storage, and notifications.
- **Official Package**: `com.android.gnsustudent`

## 🛠 Tech Stack
- **Languages**: Kotlin, Java
- **Architecture**: MVVM, Modular Dialog Controllers, Clean Architecture
- **UI & Graphics**: Custom Animated Views, Hardware Accelerated XML Drawables, BottomSheetDialogs
- **Networking**: OkHttp3, AndroidX WebKit, REST APIs
- **Media**: ExoPlayer / Android MediaSession, Video Stream Extraction
- **Computer Vision**: Google ML Kit (Barcode/QR Scanner), CameraX
- **Backend & Notifications**: Firebase Cloud Messaging (FCM), Supabase Database
